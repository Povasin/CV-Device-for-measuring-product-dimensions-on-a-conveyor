# Калибровка и трассируемость

Класс `Calibration` хранит `calibration_id` и матрицу sensor-to-conveyor 4 x 4.
Он принимает только жёсткое преобразование: финальная строка должна быть
`[0, 0, 0, 1]`, вращение должно быть ортонормальным с определителем `+1`.

Эта проверка предотвращает применение очевидно неверной матрицы в software
pipeline. Она не доказывает метрическую точность матрицы. Для физической
валидации нужны эталонная плоскость ленты, калибровочная мишень, измерение
остаточной ошибки и повторение после изменения крепления камеры.
