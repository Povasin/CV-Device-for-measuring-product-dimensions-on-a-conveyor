```powershell
uv lock --check

uv run python -m scripts.run_benchmark
uv run python scripts/build_report.py
```

## Фактические результаты программной валидации

На дату аудита выполняются 28 тестов. Demo измеряет синтетический товар
200 x 100 x 50 мм; benchmark включает 10 x 10 x 10, 200 x 100 x 50 и
400 x 300 x 300 мм. Нулевая ошибка benchmark относится только к идеальным
синтетическим точкам и не является заявлением о точности реальной камеры.

## Обязательные шаги перед production

1. Согласовать endpoint, auth и SLA WMS и реализовать конкретный transport.
2. Провести калибровку каждого сенсора и зарегистрировать residual error.
3. Собрать записи реальных товаров, материалов и окклюзий на скорости 1 м/с.
4. Подтвердить R06 по трём осям на эталонных образцах.
5. Заменить или обосновать approximate OBB, если exact MVBB остаётся требованием.
6. Инициализировать Git-репозиторий и настроить CI/hooks.
