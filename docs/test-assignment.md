# Трек Компьютерное зрение

# Вариант 1: Устройство для замера габаритов товара на конвейере

## Задача

Придумать программно-аппаратный комплекс, который решает задачу определения длины, ширины и высоты товаров, которые находятся в движении на ленте конвейера

## Вводные

Есть конвейер шириной 600 мм, по которому со скоростью 1 м/с движутся различные товары габаритами от 10x10x10 мм до 400x300x300 мм с интервалом в 3 секунды между товарами:

![][image1]

Товары на ленте могут быть произвольной формы и произвольного вида. Габариты товара определяются габаритами прямоугольного параллелепипеда наименьшего объёма, в который можно вписать товар

Для каждого товара нужно определить габариты с точностью max(5%, 5мм). То есть для товара длиной=200мм, шириной=100мм, высотой=10 мм, нужно определить длину с погрешностью ±max(200\*0.05, 5)=10мм, ширину с погрешностью ±max(100\*0.05, 5)=5мм, высоту с погрешностью ±max(10\*0.05, 5)=5мм

Считанные габариты нужно отправить в систему управления складом, которая примет решение о зоне размещения товаров на основе полученных данных о габаритах

## Ожидаемый результат

* Выбран набор сенсоров и их характеристики, предложены конкретные модели сенсоров, обоснован выбор именно таких сенсоров  
* Определено физическое расположение выбранных сенсоров  
* Подобран вычислитель, обоснован выбор локальной и/или облачной обработки данных  
* Описан алгоритм определения габаритов с момента сбора данных с сенсоров до момента отправки результатов считывания  
* При наличии нейросетей в предложенном алгоритме, обоснован выбор конкретной архитектуры нейросетей и характеристики необходимого для обучения датасета (количество изображений, способ разметки, количество классов, способы аугментации, и пр.)  
* В случае использования готовых библиотек и/или фреймворков обоснован их выбор  
* Определены ключевые метрики оценки качества предложенного решения  
* (Опционально) Реализована базовая версия предложенного алгоритма
