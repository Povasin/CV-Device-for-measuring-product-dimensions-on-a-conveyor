# Верификация реализации

## Автоматические проверки

Запуск из корня проекта:

```powershell
uv run pytest -q
uv run ruff check src tests scripts
uv run mypy src scripts
uv lock --check
uv run python -m scripts.run_demo
uv run python -m scripts.run_benchmark
```

`run_demo` измеряет синтетический параллелепипед 200 x 100 x 50 мм.
`run_benchmark` запускает три axis-aligned случая, включая минимальный
10 x 10 x 10 мм и максимальный 400 x 300 x 300 мм.

## Граница доказательств

Нулевой результат synthetic benchmark означает только, что детерминированный
pipeline согласован со своей идеализированной геометрией. Он не измеряет ошибку
depth-камеры, синхронизацию, внешнюю калибровку, движение, закрытия поверхности
или материал товара. Поэтому он не доказывает выполнение R06 на физическом
конвейере.

Перед признанием R06 выполненным необходимы эталонные образцы по диапазону R03,
повторные прогоны на скорости R04, регистрация calibration id, расчёт ошибки по
каждой оси и доли успешных измерений.

## Обработка пустого кадра

Если после удаления точек ленты остаётся менее четырёх точек, `measure_product`
выдаёт `InsufficientObjectPointsError`. Такой кадр не должен попадать в WMS как
измерение: upstream-оркестратор обязан пометить его как rejected и сохранить
диагностические данные для повторного захвата или анализа.
